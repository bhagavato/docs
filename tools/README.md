# tools

把有文本层的 PDF 还原成 Book 章节的流水线。

| 文件 | 作用 |
| --- | --- |
| `pdftext.py` | 与具体书无关的内核：抽取、去页眉、重排、脚注分离、无损校验 |
| `dipani.py` | 《三十七道品导引手册》的章节配置与重建入口 |

## 依赖

```bash
python3 -m venv .venv && .venv/bin/pip install pypdf
```

`.venv/` 不入库。

## 重建一本书

```bash
.venv/bin/python tools/dipani.py ~/path/to/Ledi_Sayadaw_Bodhipakkhiya_Dipani.pdf
```

脚本是幂等的：重跑覆盖 `content/nirodha/dipani/NN-*.md`，输出应当相同。
`_index.md` 手写，不由脚本生成。**章节的 front matter 以脚本为准**——直接编辑生成
的文件会在下次重跑时被抹掉，要改就改 `dipani.py` 里的 `CHAPTERS`。

## 先验证再写文件

`dipani.py` 在写盘前会做一次无损校验：把原始文本与重排结果都去掉全部空白，逐字
比对。不通过就中止，不会写出半成品。《道品》全书 60,464 个非空白字符，进出一致。

## 加一本新书

抄 `dipani.py` 改配置即可，需要确定四件事：

1. **有没有可用的文本层。** `/Image` 计数为 0、`/Font` 计数上百，说明是排版生成的
   文字。有些 PDF 有字体却仍不可用——CJK 子集字体缺失 `ToUnicode` 映射时，抽出来
   是南亚文字码位那样的乱码，只能走 OCR。
2. **满行宽度。** 统计行的显示宽度，分布会明显分成「满行」与「短行」两簇，取簇间
   空隙作 `reflow(full=...)`。正文与脚注的字号不同，宽度也不同，要分开量。
3. **标题清单。** 扫描全书短行后人工筛选，剔除折行产生的引文碎片。
4. **页眉与页码形态。** 页码可能印在页眉里，也可能是页末的孤立数字行；有的书还会
   把原著页码作为边注印在页边。

不对外发布的书放 `tools/local/`，该目录不入库。
